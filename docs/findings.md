# Findings

Problems with the repo itself: a rule that contradicts another, a skill step that does not work, a doc that has gone stale, a gap no skill covers. A mistake in an answer goes to `docs/corrections.md` instead.

## How to add one

Add a row with the next number (F1, F2, ...). Never reuse a number and never delete a row: when a finding is fixed, change its status and say in Evidence what was done or checked.

Status is one of `open`, `resolved`, or `superseded` (the premise no longer holds, so there is nothing left to fix as stated).
