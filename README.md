# analytics-agent-blueprint

An empty blueprint that lets a coding agent work as a governed data analyst on your warehouse. It gives the agent an operating contract, a knowledge base it fills in with you, a checklist it applies before any SQL, a receipt on every answer, and a loop that turns each correction into a better knowledge base. It ships with no business content: a setup interview maps your business, your connection, your tables, your metrics and your first golden questions.

**Quick start:** open this folder in your coding agent and say: set this up
